Assignment behavior A printer can serve only one workflow. Assigning it to a different workflow automatically leaves its former workflow or printer unassigned. An unassigned workflow cannot print. ARN routing cannot be changed while an MO/station lock or unfinished carton exists.

Printer assignment changes are restricted to the Admin role. Sign-in uses shared role passwords, so access is intended for the trusted company network only.
